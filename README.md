## 구현 기술

### 사용자 인증 및 인가 
- **JWT 기반 인증/인가** 회원가입 및 로그인 구현
- **OAuth2 (Kakao 로그인)** 연동을 통한 SNS 간편 인증
- **Spring Security**를 활용한 보안 설정 

### 관심 상품 관리
- **Naver API 연동**으로 외부 상품 검색 기능 구현
- **관심 상품 등록 및 가격 추적**, **매일 자동 가격 갱신(Scheduler)**
